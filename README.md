# Defense Fund Initiative

An AI-assisted web platform designed to support donation management
for defense-related causes.

## 🚀 Features

- User registration and login
- User profile management
- Donation form
- Donation record tracking
- Sentiment analysis of user messages
- Donation receipt interface
- Dashboard for users

## 🛠️ Technologies

- Frontend
- Backend
- Database
- AI/NLP
- Payment Gateway
- Authentication: Firebase Authentication

## 📂 Project Structure

- `index.html` – Landing page
- `login.html` – User login
- `register.html` – User registration
- `dashboard.html` – User dashboard
- `donate.html` – Donation interface
- `receipt.html` – Donation receipt
- `track.html` – Donation tracking
- `firebase-config.js` – Firebase configuration
- `script.js` – Main JavaScript logic

## ⚙️ Installation

1. Clone the repository.
2. Configure Firebase credentials.
3. Configure database and payment gateway credentials.
4. Open the application or start the backend.
5. Test authentication and donation workflows.

## 🔐 Security Notes

- Never store private payment secrets in frontend code.
- Configure Firestore security rules.
- Validate payments on the backend.
- Never trust client-generated transaction IDs.
- Protect user information and donation records.
